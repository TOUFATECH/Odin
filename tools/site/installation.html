Installation

Une commande, puis tout se règle dans le navigateur.

L'installateur s'occupe de Node.js s'il manque, installe Odin, te pose trois questions, puis ouvre l'interface web sur l'onglet Réglages. Cinq minutes.

  1. Ouvre le TerminalApplications → Utilitaires → Terminal (ou Cmd + Espace, puis « Terminal »).
  2. Colle cette commande et appuie sur Entréecurl -fsSL https://raw.githubusercontent.com/TOUFATECH/Odin/main/install.sh | bashMac Intel et Apple Silicon. Node.js 22 est téléchargé (somme de contrôle vérifiée) s'il manque, sans toucher à ton système.
  3. Réponds à trois questionsQui peut ouvrir l'interface (ton réseau local en HTTPS par défaut), inventorier ton réseau, lancer Odin au démarrage.
  4. Termine dans le navigateurL'interface s'ouvre sur Réglages : choisis ton modèle, colle ta clé (ou Ollama, sans clé), « Tester », « Enregistrer ».
  1. Ouvre un terminalUbuntu, Debian, Fedora, Arch, Raspberry Pi OS… Il faut curl et, de préférence, git.
  2. Colle cette commande et appuie sur Entréecurl -fsSL https://raw.githubusercontent.com/TOUFATECH/Odin/main/install.sh | bashSans droits administrateur : tout va dans ~/.odin. Service systemd utilisateur proposé pour le démarrage automatique.
  3. Réponds à trois questionsAccès à l'interface, inventaire du réseau, démarrage automatique. Si ufw est actif : sudo ufw allow 7777/tcp.
  4. Termine dans le navigateurRéglages → Modèle. Pour la vidéo et l'audio, installe ffmpeg (apt, dnf, pacman).
  1. Ouvre PowerShellMenu Démarrer → tape « PowerShell » → Entrée. Pas besoin de l'ouvrir en administrateur.
  2. Colle cette commande et appuie sur Entréeirm https://raw.githubusercontent.com/TOUFATECH/Odin/main/install.ps1 | iexWindows 10 et 11, x64 ou ARM. Odin s'installe dans %LOCALAPPDATA%\Odin et la commande odin est ajoutée à ton PATH.
  3. Réponds à trois questionsAccès à l'interface, inventaire du réseau, démarrage à l'ouverture de session. L'installateur propose d'autoriser le port 7777 dans le pare-feu Windows.
  4. Termine dans le navigateurRéglages → Modèle. Pour la vidéo et l'audio : winget install Gyan.FFmpeg.
  1. Vérifie Node.js 22.18 ou plus récentnode --versionSinon, installe-le depuis nodejs.org.
  2. Récupère le code et installe la commandegit clone https://github.com/TOUFATECH/Odin.git cd Odin npm install npm link odin init odin webAvec Docker : docker build -t odin . puis publie le port 7777.
  3. Tests et vérification des typesnpm test npm run typecheck

Installation sans question : ODIN_YES=1 devant la commande (et ODIN_WEB_ACCESS=local|lan|wan pour choisir l'accès). Mise à jour plus tard : odin update.

Juste après

Les premières minutes avec Odin

1

Choisis le cerveau

Réglages → Modèle : Anthropic, OpenRouter, OpenAI, Ollama (local, gratuit) ou un service compatible. Ajoute des modèles de secours et leur palier.

2

Ouvre-le sur ton téléphone

Sur le même Wi-Fi, le lien https://192.168.1.x:7777 affiché à la fin. Accepte le certificat créé par Odin après avoir comparé son empreinte dans Réglages → Accès.

3

Branche Telegram et la voix

Réglages → Telegram (jeton du bot, ton identifiant) et Réglages → Voix (transcription, synthèse, voix copiée).

4

Essaie

« Quels appareils sont sur mon réseau ? », « Résume ce PDF », « Chaque lundi à 9 h, fais le point sur mes sauvegardes ».
