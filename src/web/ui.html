Où trouver mon lien ?
Sur la machine d'Odin, tape : odin link (affiche les liens avec jeton). Odin dans un conteneur LXC (Proxmox) : depuis l'hôte, pct exec <ID> -- odin link (ou pct enter <ID> puis odin link). Odin en service : le lien est aussi dans son journal, journalctl --user -u odin | grep token. Le jeton seul est dans le fichier ~/.odin/web-token.

      Mises à jour d'Odin

        Quand une nouvelle version sort
        À chaque mise à jour, Odin garde ses propres améliorations, vérifie que la nouvelle version démarre, et revient tout seul à l'ancienne sinon. Il redémarre en quelques secondes.

        Autres messageries

        Parle à Odin où tu veux : même mémoire, mêmes habitudes, mêmes garde-fous. Les inconnus doivent toujours être appairés ; les jetons restent dans le coffre d'Odin.

        WhatsApp
        1. Sur developers.facebook.com, crée une application « Business » et ajoute WhatsApp.
        2. Copie l'identifiant du numéro, un jeton d'accès permanent et la clé secrète de l'application.
        3. Dans « Webhooks », mets l'adresse ci-dessous et la phrase de vérification que tu choisis ; abonne-toi à « messages ».
        Signal
        1. Lance signal-cli-rest-api : docker run -d -p 8080:8080 -e MODE=normal bbernhard/signal-cli-rest-api (ou demande à Odin de le faire).
        2. Relie un numéro pour Odin (QR code sur http://localhost:8080/v1/qrcodelink?device_name=odin).
        Discord
        1. Sur discord.com/developers, crée une application, puis un bot ; active « Message Content Intent ».
        2. Copie le jeton du bot ; invite-le sur ton serveur ou écris-lui en privé.
        Slack
        1. Sur api.slack.com/apps, crée une application, active « Socket Mode » (jeton xapp-…, droit connections:write).
        2. Droits du bot : chat:write, im:history, app_mentions:read, files:read ; évènements message.im et app_mention ; installe-la et copie le jeton xoxb-….
        Mail

        Écris à Odin depuis ta boîte, il répond par mail. Il utilise la boîte de Réglages → Mail et ne lit que tes mails authentifiés (un faux expéditeur est ignoré).

        Vide si la boîte est réservée à Odin.

        Recherche web

        Odin cherche sur le web, ou sur un site ou réseau précis (Reddit, X, YouTube, GitHub…). Sans rien régler, il utilise DuckDuckGo ; une clé Brave Search (gratuite jusqu'à un certain volume) ou Tavily donne des résultats plus fiables, et SearXNG reste chez toi.

        La recherche vérifiée interroge jusqu'à trois moteurs à la fois : plus tu en relies, moins Odin dépend d'un seul (mais plusieurs moteurs peuvent renvoyer les mêmes sources : Odin vérifie aussi leur indépendance).

        Droits et machines

        Odin peut tout faire sur sa machine et sur les machines de ton réseau : donne-lui simplement les mots de passe. Ils restent sur cette machine (fichiers lisibles par toi seul), ne sont jamais réaffichés ni montrés au modèle, et sont masqués partout. Les règles de sécurité restent : commandes destructrices interdites, validation selon ton niveau d'autonomie.
