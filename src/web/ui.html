Réglages

Tout se configure ici ; les clés restent sur ta machine, dans ~/.odin/env.
Bienvenue dans Odin. Il reste une étape : choisis le modèle qui fera réfléchir Odin, colle ta clé, puis « Tester » et « Enregistrer ». Sans clé, choisis Ollama pour un modèle 100 % local.

Modèle

Odin choisit le moins cher qui suffit : simple → gratuit, ordinaire → standard, complexe → le plus capable.

    Décisions

    ⚡ Odin Breaker : Odin mène ses missions sans plus rien te demander, actions graves et tâches planifiées comprises. Il discute avec toi quand tu lui parles. Il crée lui-même routines et rappels, et agit librement sur ton réseau local. Restent refusées : les commandes destructrices connues et les actions dictées par un contenu piégé. Tout est noté dans Décisions et résumé dans le rapport du soir.
    Vide : pas de rapport.

    Telegram

    1. Dans Telegram, écris à @BotFather, envoie /newbot et copie le jeton.
    2. Colle-le ci-dessous, coche « Activer » et enregistre.
    3. Écris à ton bot : il répond avec un code ; ajoute ton identifiant ci-dessous (ou accepte le code avec odin pairing approve telegram <code>).
    Les propriétaires peuvent tout demander ; les autres doivent être appairés.

    Voix

    Odin comprend ce que tu dis (Whisper) et te répond à voix haute (ElevenLabs), dans l'interface et en notes vocales sur Telegram.

    Copier une voix à partir d'un enregistrement
    Une à trois minutes de parole claire, sans musique. Envoie un fichier audio, ou enregistre-toi directement.
    OpenAI par défaut (clé OpenAI). Pour rester 100 % local, un serveur Whisper sur ta machine : http://localhost:8000/v1 (sans clé).
