Personne ne s'est encore connecté à Odin. Ce navigateur va devenir le tien : il gardera l'accès, sans jeton à recopier.

Possible une seule fois, depuis ton réseau local, pour la première configuration.

Ouvre le lien personnel d'Odin (il contient ton jeton), ou colle le jeton ici.

Où trouver mon lien ?
Sur la machine d'Odin, tape : odin link (affiche les liens avec jeton). Odin dans un conteneur LXC (Proxmox) : depuis l'hôte, pct exec <ID> -- odin link (ou pct enter <ID> puis odin link). Odin en service : le lien est aussi dans son journal, journalctl --user -u odin | grep token. Le jeton seul est dans le fichier ~/.odin/web-token.

Bienvenue dans Odin. Il reste une étape : choisis le modèle qui fera réfléchir Odin, colle ta clé, puis « Tester » et « Enregistrer ». Sans clé, choisis Ollama pour un modèle 100 % local.

Modèle

Non connecté.
Connecte-toi dans l'onglet qui vient de s'ouvrir. Si Odin est sur une autre machine (serveur, LXC…), le navigateur finit sur une page « introuvable » dont l'adresse commence par http://localhost:1455/auth/callback : copie cette adresse entière et colle-la ici.
Odin a sa propre connexion (comme Hermes a la sienne) : rien n'est partagé. Abonnement ChatGPT Plus, Pro, Business… requis. Modèles : ceux de ton abonnement (ex. gpt-6-luna).
Odin choisit le moins cher qui suffit : simple → gratuit, ordinaire → standard, complexe → le plus capable.
    Plafond atteint : seuls les modèles gratuits (installés) servent, et Odin te prévient.

    Sauvegarde

    Tout Odin (configuration, clés, mémoire, compétences, espace de travail) dans un seul fichier chiffré (AES-256, mot de passe). Garde-le ailleurs que sur cette machine ; la restauration remet tout en place sur une nouvelle installation.

    Restaurer une sauvegarde
    Remplace la configuration, les clés et la mémoire actuelles par celles du fichier (les anciens fichiers sont gardés jusqu'au prochain démarrage). Odin redémarre ses services ensuite.

    Voix

    Odin comprend ce que tu dis (Whisper) et te répond à voix haute, dans l'interface et en notes vocales sur Telegram. Avec Piper et un Whisper local, tout reste sur ta machine, gratuitement.

    Installer Piper sur cette machine (2 minutes)
    1. pip install piper-tts (ou pipx install piper-tts). 2. Lance le serveur avec une voix française : python3 -m piper.http_server --model fr_FR-siwis-medium --port 5000 — la voix se télécharge toute seule la première fois. Autres voix : fr_FR-upmc-medium, fr_FR-tom-medium, en_US-lessac-medium. 3. Laisse l'adresse http://localhost:5000, clique « Écouter un essai ». Pour qu'il démarre avec la machine, demande à Odin : « installe Piper comme service au démarrage ».
    OpenAI : alloy, nova, onyx, shimmer… Piper : vide (voix du serveur) ou le nom du modèle si le serveur en sert plusieurs.
    Copier une voix à partir d'un enregistrement
    Une à trois minutes de parole claire, sans musique. Envoie un fichier audio, ou enregistre-toi directement.
    OpenAI par défaut (clé OpenAI). Pour rester 100 % local, un serveur Whisper sur ta machine : http://localhost:8000/v1 (sans clé).
    Installer Whisper en local (gratuit, hors ligne)
    1. pip install speaches puis speaches (ou avec Docker : docker run -p 8000:8000 ghcr.io/speaches-ai/speaches:latest-cpu). 2. Adresse ci-dessus : http://localhost:8000/v1, pas de clé. Modèle conseillé : Systran/faster-whisper-small (rapide) ou large-v3-turbo (précis). 3. Enregistre, puis parle à Odin avec le bouton 🎙. Demande-lui « installe Whisper au démarrage » pour qu'il s'en occupe.
